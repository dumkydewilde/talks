### Why a coding agent is a different animal
# It gets a computer, not a chat box.
</Top>

<Block icon="fa:terminal" title="01 · A folder and a terminal" color="sky">It creates files, installs things, runs your script, reads the error, edits, runs it again. Nothing is pasted in either direction. The chat is where you talk. The computer is where the work happens.</Block>
<Block icon="fa:check" title="02 · It can check its own work" color="garden">That is the whole difference. Writing code is a guess. Running it is a fact. A coding agent gets to find out it was wrong before you do, then goes round the loop again.</Block>
<Block icon="fa:shield" title="03 · Which is why it needs a fence" color="watermelon">It has the same powers you do: delete the wrong folder, run up a bill, push to main on a Sunday. Give it its own copy of the project, a sandbox to run in, and put everything in git. Git is the undo button.</Block>
