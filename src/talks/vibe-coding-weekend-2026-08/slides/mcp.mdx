### Upgrade three: borrowed tools
# MCP is a plug socket for tools.
Nobody wants to write the code that talks to Gmail, or a browser, or a database. An MCP server is a small program that already does it and offers it to the agent as a list of tools: here is what I can do, here is what I need from you. One standard plug shape, so the same server works in whatever you use next month.

Plug in ten and it has a hundred tools to wade through before it starts. Keep the key ring small.

<Callout accent="sky">You are not adding intelligence. You are handing it a key ring.</Callout>
