### Upgrade two: give it hands
# Let it go and fetch things itself.
A tool is a plain function someone wrote: read this file, run this code, search the web, take a screenshot. The model does not do the work. It asks for the function to be run, and reads what comes back.

<Callout accent="garden">The model guesses. The tool does not.</Callout>
</Left>

<Right>
<Terminal title="what a tool call actually looks like" footerLabel="the point" footer="You pasted nothing." footerColor="garden">

```
> run("python summarise.py")

> write_file("expenses.html")

```
